OpenShift Checks (Risu Framework) Reference

This application is powered by the open-source Risu framework. Below are summaries and reference links for the upstream project.

Usage Documentation

Risu is a framework to help with system configuration validation on either a live system or a sosreport snapshot of the filesystem. By executing specific plugins, it reports on system health status, actual problems, or potential issues that will reveal themselves if no preventive action is taken.

Open Link

Plugin Development

The framework is highly extensible, allowing plugins to be written in your language of choice. It supports generating JSON output for external processing or HTML visualization, and includes native support for running Ansible playbooks.

Open Link

Contributing Guidelines

Code contributions require using pre-commit hooks and validating changes via tox. When creating or updating plugins, developers must assign a specific execution priority (e.g., 900-999 for Maximum Criticality) based on the issue's blast radius, system stability impact, and recovery difficulty.
