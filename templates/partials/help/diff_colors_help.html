Understanding Diff Colors

The Diff page compares two historical OpenShift states to determine what has changed in your cluster. The interface uses specific color-coded badges and rows to highlight how the configuration or health status has drifted between the two points in time.

CHANGED Gold: A resource exists in both temporal states, but its internal configuration or status values have been modified.[1]
DEGRADED Red: A resource or check that previously reported a healthy state is now reporting a failure or error state.[1]
RESOLVED Green: A resource or check that previously reported an error has been rectified in the newer temporal state.[1]
NEW Blue: A completely new resource (e.g., a newly deployed pod or check) is present in the newer state but was absent in the older state.[1]
REMOVED Gray: A resource that was present in the older state has been deleted or terminated in the newer state.[1]
